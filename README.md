## ✨ About the Project

> A stunning **animated creative agency website** clone inspired by the award-winning K72.ca. Built with modern web technologies to deliver a cinematic, scroll-driven visual experience.

This project combines **GSAP animations**, **video backgrounds**, and **React's component architecture** to recreate the immersive feel of a world-class creative agency website.

---

## 🎯 Key Features

| | Feature | Description |
|---|---|---|
| 🎬 | **Cinematic Hero** | Full-screen video background with bold animated headline |
| 🎞️ | **GSAP Animations** | Scroll-triggered and entrance animations throughout |
| ◈ | **Framer Motion** | Fluid page transitions and hover micro-animations |
| 🖋 | **Bold Typography** | Expressive large-scale type system like a real agency |
| 📱 | **Fully Responsive** | Mobile-first, flawless on all screen sizes |
| 🚀 | **Vite Powered** | Lightning-fast HMR and optimized builds |

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/Dev-Chandan404/K72-website.git
cd K72-website

# Install dependencies
npm install

# Start dev server → http://localhost:5173
npm run dev

# Build for production
npm run build
```
